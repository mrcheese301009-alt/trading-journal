# 📈 Pro Journal & Trading Analytics Console

A lightweight, real-time trading journal and performance analytics dashboard designed for futures, crypto, and FX traders. Built entirely with client-side web technologies and local browser persistence.

🚀 **Live Demo:** [https://mrcheese301009-alt.github.io/trading-journal](https://mrcheese301009-alt.github.io/trading-journal)

---

## ✨ Features

- **Real-Time Market Charting:** Integrated TradingView widget with a custom circular radial ticker selector supporting CME Futures (NQ, ES, MNQ), Crypto (ETH, SOL, BTC), and Forex.
- **Performance Analytics:** Auto-calculated KPI cards (Net P&L, Win Rate %, Profit Factor, Average R:R) and interactive Chart.js equity curves.
- **Monthly Performance Calendar:** Daily P&L color-coded grid with modal popups for day-specific trade breakdowns.
- **Data Import / Export:** Native CSV parser and raw spreadsheet cell paste engine for seamless migration from Google Sheets.
- **Client-Side Persistence:** Zero server overhead; all data persists locally in browser `localStorage`.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid, CSS Variables, Glassmorphism design system)
- **Scripting:** Plain JavaScript (ES6+)
- **Data Visualization:** Chart.js, TradingView Advanced Chart API
- **Data Persistence:** Browser LocalStorage API
